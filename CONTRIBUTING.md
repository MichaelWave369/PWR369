# Contributing

We welcome reproducible experiments, carefully defined models, accessibility improvements, new visualizations, and scientific references.

1. Keep the visual renderer separate from state calculations.
2. Provide a unit test for each new transition rule or parameter.
3. State units and assumptions explicitly; preserve control conditions.
4. Label subjective imagery separately from physiological measurement and from synthetic output.
5. Do not present unvalidated visual patterns as direct evidence of biological fields or metaphysical mechanisms.
6. Run `npm run check && npm test` before submitting a PR.

Please open an issue describing the hypothesis and expected outcome before major model changes.
